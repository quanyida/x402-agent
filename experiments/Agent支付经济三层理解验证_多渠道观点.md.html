① 支付协议是基础，x402 是趋势 ⚠ 方向对 · 措辞过强

你的理解：x402 = Agent 支付经济的基础层，趋势已定

② Agent 钱包/私钥基本走 MPC ✅ 大体正确 · 需补一层

你的理解：CDP、NEAR MPC 都成熟，密钥管理就靠 MPC
渠道修正：MPC 是主流密钥路线 之一（CDP 托管式 / NEAR chain-signature 式）；但 MPC 只防"密钥泄露"，不防"已授权 Agent 乱花钱"——spending policy / 限额 / 白名单 / 智能账户授权层才是关键

③ Buyer/Seller 跨链 → 桥 或 NEAR 方案 ✅ 正确 · 需补一条

你的理解：跨链桥兑换后付款，或直接用 NEAR 链抽象
渠道修正：两条路线确实成立：桥 = 资产层方案（迁移资产再付）；NEAR = 意图协调层方案（链签名 + solver）。但 NEAR 链抽象 底层仍依赖桥（verifier ledger + 外部链提款走 token bridge）；同链直连永远优先
