# x402 注册中心（Bazaar/Discovery）调研归档

日期：2026-10-11
状态：**已归档，待后续深入**
来源：官方文档 + 实测 + IETF 草案（见文末来源）

## 核心问题

> 只能查询 Coinbase 注册中心的 x402 服务，如何查询其他注册中心？现在还有哪些注册中心？

## 结论（已确认）

1. **注册中心 = facilitator 提供的 `/discovery/resources` 端点**，协议规范公开（open spec），
   **任何 facilitator 都可以实现自己的发现层**——不存在"只能查 CDP"的限制。
2. 当前脚本（`x402_bazaar.py`）只连了 CDP 一个注册中心（`REGISTRY` 常量），加参数即可切换。
3. 目录生态早期阶段（官方自称"Yahoo search"级别），但已有多个可用/在建设的目录。

## 查询其他注册中心的方法（3 种）

### ① 裸 HTTP（最简单，已验证 PayAI 可用）
```
GET https://facilitator.payai.network/discovery/resources
```
返回格式与 CDP 完全一致（`accepts/payTo/amount/network/extensions.bazaar.info`），
付费调用逻辑无需改动。PayAI 实测返回 240KB JSON。

### ② 官方 SDK 的 withBazaar 客户端（支持任意 facilitator URL）
```python
from x402.http import FacilitatorConfig, HTTPFacilitatorClient
from x402.extensions.bazaar import with_bazaar

client = with_bazaar(HTTPFacilitatorClient(FacilitatorConfig(url="https://x402.org/facilitator")))
response = client.extensions.bazaar.list_resources(...)   # 也支持自然语言 search
```
对应 Go：`bazaar.WithBazaar(facilitatorClient)`；TS：`withBazaar(facilitatorClient)`。

### ③ 改造本地脚本（待办）
给 `x402_bazaar.py` 加 `--registry` 参数，`REGISTRY` 常量可配置：
- 默认：CDP（`https://api.cdp.coinbase.com/platform/v2/x402/discovery/resources`）
- 切换：PayAI（`https://facilitator.payai.network/discovery/resources`）
- 任意：`--registry <url>`

## Bazaar 协议机制（重要背景）

- 任何支持 bazaar extension 的 facilitator 可提供 `GET {facilitator_url}/discovery/resources`；
- 资源类型：`http`（HTTP 端点）和 `mcp`（MCP 工具，用 `resource + toolName` 作为唯一标识）；
- 动态路由：参数化路径 `/users/:userId` 会被归一化后作为目录 key；
- 卖家可发布 `serviceName` / `tags` / `iconUrl` 元数据，facilitator 用于搜索增强；
- 结算后可返回 `EXTENSION-RESPONSES` header 确认 `bazaar.status`（success/processing/rejected）；
- MCP 工具发现后通过 `createx402MCPClient` 连接调用，自动处理支付。

## 去中心化发现方向（IETF 草案，未来）

`draft-hawkins-x402-dns-discovery-03`（2026-08，x402 基金会 PR 2979 评审中）：
- 域名发布 `/.well-known/x402` JSON 能力清单（facilitator/resource-server/both + 端点 + 资源列表 + 证明）；
- 可选 `_x402` DNS TXT 记录指向 manifest（未认证指针 → HTTPS 认证文档，MTA-STS 模式）；
- 客户端解析任意域名最多 1 次 DNS 查询 + 1 次 HTTPS GET；
- 安全约束：manifest 必须同域、拒绝内网目标、重定向逐跳校验、DNS 解析与实际连接防 rebinding；
- 2026-08 普查：1609 个 x402 目录主机，381 个在共享后缀下（23.6%），暂无后缀发布记录；
- 意义：中心目录变成可再生的缓存，而非"承重墙"。
